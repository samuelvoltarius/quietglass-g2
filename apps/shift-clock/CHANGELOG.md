# Changelog

## [0.3.4] — 2026-10-13

### Fixed

- Page set-up: the start-up page is created exactly once per run; after a failed draw, a reconnect or a return to the foreground it is only rebuilt (a second `createStartUpPageContainer` leaves real glasses deaf to taps and exit).
- Gestures are wired before the first page goes up, so a slow page creation can no longer swallow the double tap.
- Leaving through the system (another app, the system menu, a crash) saves the running entry and stops the per-second redraw; coming back rebuilds the page. The clock itself keeps running, as after a double tap.

### Changed

- Footers use one style across the apps: `Tippen = …`, `2× = Ende`; the stopped and running states name the exit gesture.
- German wording on the glasses: "Zeiterfassung gestoppt.", "Tippen = Projekt „Arbeit“ anlegen,".

## [0.3.3] — 2026-10-13

### Changed

- Text beside the day bar gets 46 characters per row (was 38); header and footer use the full 56 characters, so long project names and German hints are cut later.

## [0.3.2] — 2026-10-13

### Fixed

- Start language: an explicit choice is kept in the Even SDK store (the WebView's localStorage may not survive a relaunch); without one, a German-speaking Even account country (AT/DE/CH/LI/LU) starts the app in German, even when the WebView reports English.

## [0.3.1] — 2026-10-12

### Changed

- Even lifecycle alignment (system exit handling and shared runtime updates).

All notable changes to ShiftClock are documented here.
This project follows [Semantic Versioning](https://semver.org/).

## [0.3.0] — 2026-10-07

### Changed

- Store readiness: system exit dialog, privacy policy.
  - A double tap on the root screen now opens the system exit dialog
    (`shutDownPageContainer(1)`). Cancel and the app carries on unchanged;
    timers, streams and sensors stop only after you confirm. A failed call
    is caught and leaves the app running.
  - The running entry is saved before the dialog appears.
  - `docs/PRIVACY.md` covers every permission in `app.json`, with a German
    summary, and is linked from the README.
  - Store art in `store/` (icon, 24 px monochrome icon, background,
    tagline), generated by `tools/store-art.mjs`.

## [0.1.0] — 2026-09-25

First release.

### Added
- Hands-free time tracking: tap to choose a project and start, tap to stop.
- Project switching in a single move — the open entry closes and the next one
  opens at the same instant, leaving no gap and no state where the clock runs
  against nothing.
- The open entry is persisted as it happens, so a crash, a flat phone or a
  dropped Bluetooth link cannot lose tracked time.
- Leaving the app does not stop the clock; ending a shift is always explicit.
- Entries under 10 seconds are discarded as fumbles.
- The day total on the glasses includes the entry still running.
- Project picker opens on the most recently used project.
- CSV export with decimal hours alongside seconds, for invoicing.
- Phone companion for projects, today's entries, all-time totals and export.
- 40 unit tests covering start/stop/switch semantics, fumble rejection, daily
  filtering, CSV quoting, storage validation and the display.

### Known limitations
- Entries cannot be edited on the glasses.
- Overlapping entries are not supported.
- No billing-increment rounding; raw seconds are recorded.
- Not yet verified on physical hardware.
