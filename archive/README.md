# Archive

Apps that are no longer developed. The code stays here for reference: each
one still builds and its tests still pass, but it is not part of the release
set, the screenshot gallery, or `tools/verify-all.ps1`.

They were retired on 2026-10-06 because the G2 already does the same job out
of the box, or another Quietglass app covers it:

| App | Why it was archived |
|---|---|
| [PromptFlow](promptflow) | The G2's built-in **Teleprompt** scrolls with your speaking pace. |
| [Dayline](dayline) | The G2 **Dashboard** shows your phone calendar. |
| [Companion](companion) | The G2's built-in **Even AI** is a push-to-talk assistant; Agent Glass covers self-hosted agents. |
| [Map Glass](map-glass) | Merged into [OpenGlance](../apps/openglance-nav), which now has its route overview. |

To bring one back, move its folder to `apps/` again.
