## Findings, safety first

1. ❌ decibel-guard `decibel-guard/src/main.ts:341-342`: single tap stops measuring, no arm. (verified)
2. ❌ quiet-hub `quiet-hub/src/hub/model.ts:693-698`: swipe in Zuhause detail dims lights / opens-closes covers; tap toggles a light or stops a cover. CHANGELOG 0.8.1 calls the unarmed tap deliberate, but it contradicts "swipe never changes data". (verified)
3. ⚠ xaventra-hud `xaventra-hud/src/main.ts:287-290`: voice result answered_ja/nein answers the card on release with no second tap (verified); hold+release sends free text in one gesture (`messages.ts:168`).
4. ⚠ babel-glass `babel-glass/src/main.ts:996-1028`: menu "Meine Stimme löschen" deletes a voice print in one click; "Kunde wechseln/Modus/Personen" (`:1030-1050`) restart a running listen unconfirmed. Swipe at live edge triggers `translateMyLast` (`:1201`).
5. ⚠ 2x that stops/discards a job: babel-glass `main.ts:1103-1109` and decibel-guard `main.ts:228-234` stop listening/measuring before the exit dialog (resume on cancel); quiet-hub `hub/model.ts:410-415` discards a recording; shoot-day `main.ts:1110` cancels dictation; openglance-nav `main.ts:1941` ends route-choice start unconfirmed. babel phone text `messages.ts:310` "Stoppt nie Untertitel" is therefore partly wrong.
6. ⚠ Swipe changes/saves data: field-log `main.ts:~560-575` (severity); flowlist `input/dispatch.ts:~58` + `checklist/run.ts:102-124` (swipe up un-does a step; CHANGELOG claim only true for down), `dispatch.ts:67-70` swipe down arms skip; cadence `main.ts:252-259` tempo (declared exception); endurance-hud `main.ts:140` sport; openglance-nav `main.ts:1886-1892` view toggle.
